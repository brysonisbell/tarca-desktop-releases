# Tarca desktop downloads

Public installers for the Tarca desktop app. Tarca's application source is maintained separately; this repository contains release information only.

## Version 0.2.0 — unsigned preview

[Choose a Mac or Windows download](https://github.com/brysonisbell/tarca-desktop-releases/releases/tag/v0.2.0-preview).

These preview installers are **not developer-signed**. Mac builds are not Apple-notarized. Your operating system may warn or block installation. Automatic desktop updates are not configured. Use the web app at [tarca.app](https://tarca.app/) if you prefer to wait for signed installers.

| Computer | Installer |
| --- | --- |
| Mac with Apple Silicon (M-series) | `Tarca-0.2.0-mac-arm64.dmg` |
| Mac with an Intel processor | `Tarca-0.2.0-mac-x64.dmg` |
| Windows with an Intel/AMD x64 processor | `Tarca-0.2.0-win-x64.exe` |
| Windows with an ARM64 processor | `Tarca-0.2.0-win-arm64.exe` |

Version 0.2 adds encrypted meeting-recording recovery, movable floating recording controls, and optional meeting reminders. Finish any recording and quit Tarca before installing this update over the existing app.

The desktop app opens the same online Tarca workspace in a dedicated window. Previously downloaded tasks and project overviews can be read offline in an encrypted local copy. Offline editing, offline attachments, and a complete offline workspace are not included.

Public download access does not include a Tarca account or subscription. Normal sign-in, access and plan requirements apply. Installed provider connections, payments and meeting audio retain separate verification limits; a successful package build is not a guarantee for every device or workflow.

Each release includes SHA-256 checksums. The GitHub-generated “Source code” archives contain only this download repository's release information, not the Tarca application.
